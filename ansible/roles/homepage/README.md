# Role `homepage`

Moved from `AGENTS.md` (agent-facing notes, kept in English); the index there links here.

## Widgets

- Homepage widgets (`ansible/roles/homepage`, `services.yaml`, queried server-side): Beszel on its link (widget version 2 logs in as a PocketBase **superuser**, so a dedicated one, `beszel_homepage_email` in `host_vars/docker`, SOPS `homepage_beszel_password`, created or reset by the `beszel` role with `docker exec beszel /beszel superuser upsert` whenever its password is refused (400) — Molecule swaps in `beszel_superuser_command`; accepted risk: that superuser can read and write the whole hub, so whoever reads Homepage's config owns Beszel). The hub has PocketBase `superuserIPs` set (in the UI: one public IP, plus `172.16.97.3` since 2026-10-29): a superuser with the right password from any other source gets 403 « You are not allowed to perform this request. », so Homepage reaches the hub over its own internal network `beszel_homepage` (fixed subnet and IPs in `host_vars/docker`, created by `dc@beszel`, joined as external by Homepage; the widget URL is the hub's IP there, not its name) and its fixed IP `beszel_homepage_client_ip` must be added to that list by hand. The account step never fails the play: 403 counts as a valid account (from the host the source is the Docker gateway), any other failure warns and sets `beszel_homepage_account_ready: false`, which drops the widget for that run. On since 2026-10-29 (`beszel_homepage_email: ""` turns it off; steps both ways in `docs/architecture.md`, « La supervision »), and one Uptime Kuma card per published status page of `homepage_uptimekuma_status_pages` — only `sylvain-dev` (slug pinned by the `homepage_status_pages_match_the_role` test): the backups get no public status page, by decision. URL from the `homepage_uptimekuma_url` output (`status_page_site.tf`) read by `docker.yml`. Either half is skipped when its credential or URL is empty. Also: header widgets (search, datetime, Open-Meteo), a `siteMonitor` dot on every link whose internal address is known (`internal_url`/`site_monitor` fields of `homepage_links`: Pangolin's target and probe path, Docker VM targets only; LAN IPs set in the role for the Pi's Immich, Jellyfin, Proxmox; none for flip), one Beszel card per `beszel_agent_tokens` key (group Hôtes, `systemId`), and `homepage_link_widgets_extra` (Proxmox, Pangolin with the `homepage_pangolin_org` output, Speedtest Tracker, Immich, Jellyfin, Homebox, Karakeep) plus an iCal agenda card, each rendered only when its optional SOPS key `homepage_*` is non-empty (role defaults read them with `| default('')`; Molecule renders the config both with and without them). Jellyfin/Homebox/Karakeep credentials are not read-only: accepted risk (Sylvain, 2026-10-29, `docs/architecture.md`). Token creation: `docs/runbooks/rotation-des-secrets.md#widgets-de-homepage`.
