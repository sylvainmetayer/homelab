# Role `jellyfin`

Moved from `AGENTS.md` (agent-facing notes, kept in English); the index there links here.

Part of `nas.yml` (row in `docs/conventions/ansible.md`): `dc@jellyfin`, media from the UGOS shared folder `media` mounted `:ro`; the role asserts the share and its library folders before writing anything, under its own tag only. TLS in front: `ansible/roles/nas_proxy/README.md`.

Jellyfin itself sits on its project's `media` network only (`jellyfin_media` for Docker, fixed subnet, created by `dc@jellyfin` and joined as external by `nas_proxy`, hence `nas_proxy` after `jellyfin`; Traefik at `172.30.96.10`, the IP set in Jellyfin's "Known proxies") and keeps `8096` published on the LAN as a fallback.

Quick Sync (N100 iGPU, `i915`): the compose passes `jellyfin_render_device` (`/dev/dri/renderD128`) and adds the group that owns it (`render`, gid 105 on the NAS, read by `stat` at deploy, never hard-coded; the role refuses gid 0). `card0` is not needed. The Jellyfin-side settings live in Jellyfin's own files, not here (transcoding in `config/config/encoding.xml`, subtitle preferences in the database and the libraries' options, all under `config/`, so in borg), set on 2026-11-02: Dashboard › Playback › Transcoding on Intel QuickSync, device `renderD128`, hardware decoding of H.264, HEVC (10-bit, RExt 8/10-bit and 12-bit), MPEG-2, VC-1, VP8, VP9 (10-bit) and AV1, native VA-API decoders preferred (the default, hence `-hwaccel vaapi` below), low-power H.264/HEVC encoders, HEVC encoding allowed, AV1 encoding off (the N100 decodes AV1 but does not encode it), tone mapping OpenCL (handles Dolby Vision profile 5; VPP off). Check from the NAS, with `sudo` (`sylvain` is not in the docker group on UGOS, and the project dir is root's, `0700`): `sudo docker exec jellyfin /usr/lib/jellyfin-ffmpeg/vainfo --display drm --device /dev/dri/renderD128`; a transcode's log (`sudo ls /volume1/docker/jellyfin/config/log/FFmpeg.Transcode-*.log`) shows `-hwaccel vaapi` and `h264_qsv -low_power 1`. Subtitles: user preference French, mode Smart; Films and Séries download French then English, which takes effect only once a subtitle provider plugin (OpenSubtitles, account needed) is installed.

Backup (tag `backup`, `jellyfin_backup_enabled`, default true): `config/` and the compose through the shared borgmatic template, run by the NAS's containerised borgmatic (02:30, `ansible/roles/borgmatic/README.md`); the SQLite databases `config/data/*.db` are copied by `sqlite3` (`VACUUM INTO` in WAL, `.backup` otherwise), their live copy excluded. Push monitor « Backup Jellyfin » (`tofu/pangolin_config/backup_jellyfin.tf`, outside `local.websites`: Jellyfin is no public resource), restore-tested (`.github/restore-test/apps.json`). The media are not in borg.
