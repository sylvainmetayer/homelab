# Hosted apps

Each app is an Ansible role (`ansible/roles/<role>`) deployed by the playbook of its host, and its Pangolin route is an entry in `tofu/pangolin_config/website_<name>.tf`. Unless noted, Pangolin asks for SSO login before it lets a request through.

This table is the reference list of the apps; AGENTS.md points here instead of repeating it. The playbooks are `ansible/docker.yml` (Docker VM), `ansible/pi.yml` (Raspberry Pi), `ansible/flip.yml` (flip), `ansible/pangolin.yaml` (Pangolin VM), `ansible/lxc.yml` (the Newt LXC: Blocky) and `ansible/nas.yml` (the NAS, run by hand: NFS exports, the Beszel agent, its Newt, Jellyfin, the NAS's Traefik, `nas_proxy`, and the kDrive copy, `kdrive_sync`). To add, pause or remove an app, see the `new-app` and `remove-app` skills under `.claude/skills/` and [conventions/app-lifecycle.md](conventions/app-lifecycle.md).
